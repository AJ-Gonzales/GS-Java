# 🌱 UrbanFarms

O projeto faz parte da proposta UrbanFarms, voltada ao uso de tecnologia e dados de satélites no contexto de fazendas urbanas. 
A API permite realizar o gerenciamento de fazendas e satélites, com operações de consulta, cadastro, atualização e exclusão.

## Tecnologias

- Java 17
- Spring Boot 3.5.14
- Spring Web
- Spring Data JPA
- Spring Validation
- H2 Database
- Lombok
- Maven

## Como executar

Clone o repositório:

```bash
git clone https://github.com/AJ-Gonzales/GS-Java.git
```
Entre na pasta:
```bash
cd GS-Java
```
Execute a aplicação:

Windows
```bash
mvnw.cmd spring-boot:run
```
Linux/macOS
```bash
./mvnw spring-boot:run
```
A API será iniciada localmente e poderá ser acessada pelos endpoints disponíveis no projeto.
